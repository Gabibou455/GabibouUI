## Add your first control

Run this in a client environment that supports `loadstring` and `game:HttpGet`:

```lua
local UI = loadstring(game:HttpGet('https://raw.githubusercontent.com/Gabibou455/GabibouUI/main/gabibou_ui.luau'))()
local window = UI:CreateWindow('My project')
local tab = window:Tab('Home', 'home')
tab:Toggle('Effects', function(enabled) print('Effects:', enabled) end)
```

The toggle starts off by default. Its callback receives the new boolean when the player changes it; the callback does not run just because the control was created.

To choose a different starting value, pass an options table: `tab:Toggle('Effects', {Value = true}, callback)`. Use `tab:Section('Settings')` when you want to group related controls.

Read or update a value control later:

```lua
local effects = tab:Toggle('Effects', function(enabled) print('Effects:', enabled) end)
print(effects:Get())
effects:Set(true) -- Updates the value without calling the callback.
effects:Set(false, true) -- Updates the value and calls the callback if it changed.
```

For Roblox Studio, add the library as a `ModuleScript` in `ReplicatedStorage` and load it with `require`; see [Installation](/getting-started/installation). The `main` loader URL follows repository updates; use a published release tag to pin a version.
