## Before you begin

Choose an installation method in [Installation](/getting-started/installation). The example below uses the remote loader, which needs a client environment that supports both `loadstring` and `game:HttpGet`. In that environment, paste the **whole code block** into its client code editor and run it. If you use Roblox Studio, follow the ModuleScript steps on the installation page. In the code block below, replace its first line with the two `require` lines shown there; keep the window and control lines in the same `LocalScript`.

## Build a window with a toggle

```lua
local UI = loadstring(game:HttpGet('https://raw.githubusercontent.com/Gabibou455/GabibouUI/main/gabibou_ui.luau'))()
local window = UI:CreateWindow('My project')
local tab = window:Tab('Home', 'home')
tab:Toggle('Effects', function(enabled)
    print('Effects:', enabled)
end)
```

After you run the code, a window titled **My project** appears with a **Home** tab and an **Effects** toggle. Click the toggle: it switches on or off, and the client output shows `Effects: true` or `Effects: false`.

Here is what each line does:

1. `loadstring(...)()` downloads and loads the library. `UI` is the library object used to create your interface.
2. `UI:CreateWindow(...)` creates the main panel. A **window** is the panel that holds your menu.
3. `window:Tab(...)` adds a page to the window. A **tab** is one page of the menu; `'Home'` is its label and `'home'` is its icon name.
4. `tab:Toggle(...)` adds a control to that page. A **control** is an interactive item such as a toggle, button, or slider.

The second argument to `Toggle` is a **callback**: a function the library runs when the player changes the toggle. `enabled` is `true` when it is on and `false` when it is off. Creating the toggle does not run the callback. The toggle starts off by default.

## Add another control

Add this line **below the `tab:Toggle(...)` block**, before the end of your script. It creates a button on the same Home tab:

```lua
tab:Button('Say hello', function()
    print('Hello!')
end)
```

A **button** runs an action when clicked. Its callback has no input value because there is no setting to report. You should see `Hello!` in the client output after clicking it.

You can group related controls under a heading. Add these lines below the button:

```lua
local settings = tab:Section('Settings')
settings:Toggle('Music', function(enabled)
    print('Music:', enabled)
end)
```

`Section` adds a heading inside the existing tab and returns an object named `settings`. Add controls to that object just as you add them to `tab`.

## Start the toggle on

To start the original Effects toggle on, find its line in the complete example and replace it with this version:

```lua
tab:Toggle('Effects', {Value = true}, function(enabled)
    print('Effects:', enabled)
end)
```

`Value` is an option that sets the starting value. It does not run the callback. If you omit `Value`, the toggle starts off.

## Read or change a value later

To keep a reference to the toggle, assign the returned control to a variable. Replace the original Effects line with these lines, then add the final two lines where you want to read or change it:

```lua
local effects = tab:Toggle('Effects', function(enabled)
    print('Effects:', enabled)
end)

print(effects:Get()) -- reads the current value
effects:Set(true) -- turns it on without calling the callback
effects:Set(false, true) -- turns it off and calls the callback if it changed
```

`Get()` reads the value. `Set(value)` changes it without running the callback. `Set(value, true)` also runs the callback if the value changed. Indentation is optional in Lua; keep the three lines together in the same script.
