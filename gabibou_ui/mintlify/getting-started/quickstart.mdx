## Build a window

This complete example uses the short API. The loader requires a client environment with `loadstring` and `game:HttpGet`.

```lua
local UI = loadstring(game:HttpGet('https://raw.githubusercontent.com/Gabibou455/GabibouUI/main/gabibou_ui.luau'))()

local window = UI:CreateWindow('My project')
local tab = window:Tab('Home', 'home')

tab:Button('Say hello', function()
    print('Hello!')
end)

tab:Toggle('Effects', { Value = true }, function(enabled)
    print('Effects enabled:', enabled)
end)
```

`Value` sets a control's starting value. The toggle starts off when `Value` is omitted; its callback receives the new boolean when the player changes it. The callback does not run just because the control was created. A button callback runs when clicked and receives no value.

The same controls accept an options table, for example `tab:Toggle({Title = 'Effects', Value = true, Callback = function(enabled) print(enabled) end})`. Use `tab:Section('Settings')` to group controls.

For Roblox Studio, add the library as a `ModuleScript` in `ReplicatedStorage` and load it with `require`; see [Installation](/getting-started/installation). The `main` loader URL follows repository updates; use a published release tag to pin a version.
