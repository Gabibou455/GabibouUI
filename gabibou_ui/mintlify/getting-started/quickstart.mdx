## Load the library

In a client environment that supports `loadstring` and `game:HttpGet`, load the current source with one line:

```lua
local UI = loadstring(game:HttpGet('https://raw.githubusercontent.com/Gabibou455/GabibouUI/main/gabibou_ui.luau'))()
```

The `main` URL follows repository updates. Use a published release tag in the URL when a project needs a fixed version. See [Installation](/getting-started/installation) for other setup options.

## Create a window

```lua
local window = UI:CreateWindow('My project')
local tab = window:Tab('Home', 'home')
tab:Button('Hello', function()
    print('Hello!')
end)
```

The same title-first style works for common controls:

`tab:Toggle('Effects', function(enabled) print('Effects:', enabled) end)` adds a toggle that starts off by default. Use `tab:Section('Settings')` to add a section. The window and tab can also take options tables. Buttons and toggles accept a callback or options table after the title; sliders, inputs, dropdowns, keybinds and color pickers accept an options table and optional callback. Paragraphs display text and do not take callbacks. Existing table-based calls remain supported. Browse [Controls](/customization/controls) and [Appearance and layout](/customization/appearance-and-layout) for optional configuration.
