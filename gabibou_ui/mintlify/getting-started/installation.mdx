title: Installation
description: Load Gabibou UI in a supported client or Roblox Studio.
---

## Recommended: one-line client loader

In a client environment that supports `loadstring` and `game:HttpGet`, paste this line:

```lua
local UI = loadstring(game:HttpGet('https://raw.githubusercontent.com/Gabibou455/GabibouUI/main/gabibou_ui.luau'))()
```

This follows updates on `main`. To keep a fixed version, replace `main` with a published release tag from [GitHub Releases](https://github.com/Gabibou455/GabibouUI/releases).

This loader needs both `loadstring` and `game:HttpGet`. Standard Roblox Studio does not provide this loading route.

## Roblox Studio: ModuleScript

For a standard Studio project:

1. Add a `ModuleScript` named `GabibouUI` under `ReplicatedStorage` and paste in the standalone source file `gabibou_ui.luau`.
2. Require it from a client `LocalScript`:

```lua
local ReplicatedStorage = game:GetService('ReplicatedStorage')
local UI = require(ReplicatedStorage:WaitForChild('GabibouUI'))
```

Continue with the [quickstart](/getting-started/quickstart) to create your first window. Keep private credentials and key lists on the server; see [server validation](/examples/server-validation) for an example.
