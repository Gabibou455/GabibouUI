## Local layout limits

Controls accept `Layout = {Order, Width, Height, Position}`. `Order` is an integer from -100000 to 100000, `Width` is 58-600 px, `Height` is 44-160 px and `Position` accepts `Left`, `Right` or `Below`. Tabs accept `Order`, `Width`, `Height` and `IconSize` (12-40 px).

Style text sizes accept 10-32, corner radii 0-32, and `RowPadding` 8-32. Out-of-range layout and style options are rejected. `Duration` and `Delay` accept 0-30 seconds; `RepeatCount` is an integer from -1 to 100.

## Colors and icons

Theme tokens are `Background`, `Surface`, `Raised`, `Hover`, `Border`, `Text`, `Muted`, `Accent`, `AccentText`, `Success`, `Danger`. Partial theme tables inherit omitted colors from Graphite.

`Branding` accepts `Mode` (Initials, Avatar, Image), `Placement` (TopLeft, TopRight, BottomRight, BothRight), `Text`, `Image` and `UserId`. Icon variants are `Outline`, `Soft`, `Duotone`. See [Icons](/reference/icon-catalogue).
