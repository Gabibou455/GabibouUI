Gabibou UI includes 96 original vector drawings. Each number is an **internal library ID**, not a Roblox image asset ID; built-in icons are drawn by the library and need no asset upload. IDs stay stable, and future built-in icons are appended.

Use an icon name or numeric ID in a tab or control. For example: `window:Tab({Title = "Farm", Icon = 21})` or `tab:Button({Title = "Harvest", Text = "Collect", Icon = "harvest"})`. These previews show the Outline variant. See [Icons and branding](/customization/icons-and-branding) for `Soft` and `Duotone` variants, lookup methods, and custom icon builders.

## Use names or IDs

```lua
local farmTab = window:Tab({Title = "Farm", Icon = 21})
farmTab:Button({Title = "Harvest", Text = "Collect", Icon = "harvest"})

local id = UI:GetIconId("harvest") -- 24
local name = UI:GetIconName(21) -- "farm"
for _, entry in ipairs(UI:GetIconCatalogue()) do
    print(entry.Id, entry.Name)
end
```

Lookup methods return `nil` for unknown names or IDs. Names are exact and case-sensitive. `GetIconCatalogue()` returns a copy. Unknown or non-integer IDs are rejected before a GUI icon is allocated.

## Variants and custom icons

`Outline` is the default icon style. `Soft` and `Duotone` are also available. Tabs and buttons use `IconVariant`; `UI:Icon` accepts `Variant` or `IconVariant`.

```lua
local icon = UI:Icon(parent, "farm", {Size = 24, Variant = "Duotone"})
local sameIcon = UI:Icon(parent, 21, {Size = 24, Variant = "Soft"})
```

`UI:RegisterIcon(name, builder)` registers a custom vector builder. Custom IDs start at 1000 and increase monotonically within that library instance; they depend on registration order and are not persisted across instances. `UI:UnregisterIcon(name, expectedBuilder)` removes the registration and does not reuse its ID. Built-in IDs 1–96 never change.
