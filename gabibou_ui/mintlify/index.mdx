## What the library provides

- Declarative and step-by-step window creation.
- Toggle, slider, dropdown, input, keybind, color picker, button, paragraph, and custom controls.
- Persistent values, configuration snapshots, and caller-provided storage adapters.
- Responsive layouts, three navigation styles, and 96 original vector icons.
- Custom themes, managed animations, event subscriptions, and cleanup ownership.
- Loading screens, optional key validation UI, Discord invite controls, and startup orchestration.

The key gate is client UI. Validate access and every protected action on your server. The library does not store secrets or provide server authentication.
