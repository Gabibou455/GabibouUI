Gabibou UI helps you build menus for a Roblox game. A **window** is the main menu panel. A **tab** is a page inside that window. A **control** is something the player can use, such as a button or a toggle.

You will first load the library, then create a window and a tab, then add a control. The [Quickstart](/getting-started/quickstart) explains each line and shows what to expect.

Choose the installation guide before running code. The remote loader requires a client environment that supports `loadstring` and `game:HttpGet`. In standard Roblox Studio, put the library in a `ModuleScript` and load it from a `LocalScript`.

For more complete projects, browse [examples](/examples/quickstart). If your interface protects an action or account, check that action on the server; a client interface alone cannot enforce access.
