Gabibou UI is a Luau library for building Roblox client interfaces. Load it with one line in a client environment that supports `loadstring` and `game:HttpGet`, then create a window and add controls with a few calls.

```lua
local UI = loadstring(game:HttpGet('https://raw.githubusercontent.com/Gabibou455/GabibouUI/main/gabibou_ui.luau'))()
local window = UI:CreateWindow('My project')
local tab = window:Tab('Home', 'home')
tab:Button('Hello', function() print('Hello!') end)
```

The `main` URL follows repository updates. Use a published release tag to keep a project on a fixed version. Standard Roblox Studio client scripts use a `ModuleScript` and `require`; see [Installation](/getting-started/installation).

## What the library provides

- Buttons, toggles, sliders, dropdowns, inputs, keybinds, color pickers, paragraphs, and custom controls.
- Optional values, configuration snapshots, and caller-provided storage adapters.
- Responsive layouts, navigation styles, and a catalogue of vector icons.
- Custom themes, animations, event subscriptions, and cleanup ownership.
- Loading screens, optional key validation UI, Discord invite controls, and startup orchestration.

The key gate is client UI. Validate access and every protected action on your server. The library does not store secrets or provide server authentication.
