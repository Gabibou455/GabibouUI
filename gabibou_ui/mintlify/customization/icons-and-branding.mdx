## Native icons

Gabibou UI includes 96 original vector icon designs with stable IDs. Use a name or numeric ID in tabs, buttons, and notifications. `UI:GetIconId(name)`, `UI:GetIconName(idOrName)`, and `UI:GetIconCatalogue()` map the stable catalogue. `UI:GetIconNames()` lists names; `UI:GetIconVariants()` returns `Outline`, `Soft`, and `Duotone`.

```lua
local farm = window:Tab({Title = "Farm", Icon = 21})
farm:Button({
    Title = "Harvest",
    Text = "Collect",
    Icon = "harvest",
    IconVariant = "Duotone",
    Callback = function()
        print("Connect your own action here")
    end,
})

local harvestId = UI:GetIconId("harvest")
```

See the [complete icon catalogue](/reference/icon-catalogue) for all 96 names and IDs. Icon IDs belong to this library; no image asset is required for built-in drawings.

## Navigation variants

Set window navigation with `Navigation = {Variant = "Soft", IconVariant = "Outline"}` or call `window:SetNavigation(options)`. Variants are `Classic`, `Soft` (default), and `Pill`; icon variants are `Outline`, `Soft`, and `Duotone`. A tab can provide `IconVariant` to pin its own icon style. Buttons can also set `IconVariant`.

`UI:RegisterIcon(name, builder)` registers a custom vector builder. `UI:UnregisterIcon(name, expectedBuilder)` removes a registration, optionally checking the expected function to avoid removing another module's registration.

## Window branding

Window branding uses an initial, avatar, or custom uploaded image. Configure it with `Branding` at window creation or `window:SetBranding(options)`. Supported placements are `TopLeft`, `TopRight`, `BottomRight`, and `BothRight`. Image mode accepts an `rbxassetid://<digits>` URI. Avatar mode uses Roblox's thumbnail service; it is not a remote download from this documentation site.

```lua
local window = UI:CreateWindow({
    Title = "Garden Tools",
    Branding = {Mode = "Avatar", Placement = "BothRight"},
})
```

For the key gate's separate logo and Discord mark, see [Key systems](/customization/key-systems).
